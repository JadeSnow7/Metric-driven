# 委派与交接

## 什么时候委派

在边界明确、文件所有权可隔离、委派有实际收益且环境和授权就绪时，把实现交给 coder。委派前主线程必须完成 Spec 条目检查：范围、约束、交付物、验证方法和证据位置均已明确。主线程负责需求、架构、共享契约、最终审查、整体验收和沟通。Claude Code 使用 Sonnet 的 `veriflow-coder` 与 `veriflow-reviewer`，见 [claude-code.md](claude-code.md)。

实现合同包含目标、可写路径、基线、接口约定、验收和证据位置；按 [design.md](design.md) 添加适用的入口与接入位置、实际执行路径、模块职责、依赖方向、契约来源与消费者、状态或副作用归属及兼容条件。设计内容可直接引用权威说明的具体位置。

合同同时引用测试基准及实现前结果；尚未建立时先委派基准编写与运行，产品实现等待主线程核查。完成回报包含实现前后记录及基准变更原因。步骤见 [workflow.md](workflow.md) 的“先写测试基准”。

子代理长时间无修改时，先核查环境，可给出只含任务所需文件的隔离副本，再缩小范围重派；持续受阻时由主线程接手，说明实际实现与审查分工。

## 写入所有权与审查

- 每个文件同一时间指定一个写入者，共享状态由主线程维护。
- 源码、正文、验证和封存可由各所有者分阶段完成；交接标明依赖，同步后完成整体交付。
- 共享接口变更由主线程先更新契约，再分派消费者改动。
- 主线程读取实际 diff 和原始记录，按 [design.md](design.md) 核对接入、契约效果、占位与替换收尾，并核对合同及文档；匹配当前 revision 且支持结论的子代理证据可直接采用。
- 主线程亲自运行整体验收和至少一个区分性检查；缺失、过期或相互矛盾的证据标为 `undetermined` 并补充核验。
- 若验收要证明过程，委派合同须在执行前列出可采集的原始工具输出、事件或时序观察及其保存位置；执行者负责采集并回报这些材料，主线程核对其是否支持结论。材料缺失时收窄结论，不以最终产物替代过程证据。

## 子任务完成回报

每个子任务完成后立即回报：结果、产物路径与接入位置、验证与证据、文档同步、未完成项、下一依赖或阻塞；沿现有合同字段引用契约及状态归属，不另建交接状态体系。主线程核查后更新用户进度与摘要；待核查产物标为“完成待审查”。报告完成前主线程逐项对照 Spec 核对交付物、有效证据和未满足项；交付动作继续按各自授权执行。

## 最小充分交接包

需要下一执行者接手时，使用 `assets/templates/handoff.md`，填写适用内容：

1. 任务编号、目标与来源；
2. 基线提交、工作目录与改动所有权；
3. 范围、可写路径、接口、设计约束与依赖；
4. 验收、证据、已采纳决定与待决事项；
5. 影响下一步的失败经验、下一步及停止条件。

现有摘要、契约和证据直接引用路径。整合清单写明来源 revision、目标 base、可写路径与逐文件哈希，用 `scripts/integrate_boundary.py` 核对后复制。

该工具核对 HEAD，并用文件哈希验证工作内容；删除与重命名单独安排步骤。复制按文件进行，磁盘或权限错误后核验目标实际状态，再决定恢复方式。主线程核验审查结论及目标文件归属。

调用示例：`python3 scripts/integrate_boundary.py --source-root /tmp/source --target-root /tmp/target --manifest manifest.json --source-revision REV --target-base BASE --allowed-path src`。manifest 包含 `source_root`、`target_root`、`files`，文件项包含 `source`、`source_sha256` 和 `target_sha256`。

## 写作文档的附加信息

跨 Agent 写作交接补充大纲、术语、事实来源、章节归属、引用格式与整合负责人，按需使用 `assets/templates/writing-handoff.md`。写作者维护自己的章节与证据，整合负责人串行处理主稿、交叉引用与事实冲突。行为或约定变化时同批同步相关文档；待同步项列入剩余工作。

## 独立行为评估

复杂或高风险流程可安排独立前向评估：只提供真实请求、skill 和最少原始材料，让评估者自行得出结论。产物放在临时隔离目录，外部依赖使用评估专用资源。涉及额外权限或用量时，先确认相应条件。主线程读取实际产物，按观察到的问题修订；Claude Code 做法见 [claude-code.md](claude-code.md)。
