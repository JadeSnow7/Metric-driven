# 独立前向检查

一个无父会话历史的独立代理，显式读取冻结候选 skill，完成三个子任务：仅修正文档标题；从提供的实验材料给出产品、速度、过程与成本判断；判断导入与故障检查的验收状态和下一步。输入没有提供预期答案或修复建议，允许写入仅 materials/README.md 与 output/。停止条件是单次终结或8分钟。

materials.json 是合成场景，采用历史观察中的数值和失效形态，但5项交付/3项完成、用量字段与测试结构是本次夹具，不是新的历史实验事实。评估者不承担真实导入器或worker实现。

reviewer-report.md 是独立代理产物，不冒充其工具原始日志。本轮未完整采集该代理内部时序，因此只评价最终判断和可读回的标题变化，不声称过程自动遵循、自动触发或相对旧版收益。primary-behavior-check.json 是主线程亲自执行的最小复核，已绑定隔离候选与输入字节；与评估者自述执行分开。
