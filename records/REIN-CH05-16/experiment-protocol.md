# 冻结的实验协议

估计对象是在共同详细产品计划、相同前置工程和环境下，执行coder额外加载本次冻结skill的增量。代表章05/08/12/14，每章两组各一次；两组均交付两种语言代码与完整正文。

共同产品规格与原始写作参考相同，不把EDD工作流或模板写进控制组提示。实验组额外获得冻结skill路径。两组目录隔离，禁止读取另一组、评分、主线程历史、长期记忆和实验管理材料。

## 执行入口修订（正式实验前）

内置协作工具在准备阶段反复拒绝新建及恢复代理，返回 agent thread limit reached；完成代理后仍不能可靠创建全新执行者。此基础设施问题及准备返工不计入任何章节首轮成绩。正式两组统一改用本机 Codex 0.154.0 的 `codex exec --ephemeral --json --approve-for-me`，每次启动全新进程、不给 resume/session 历史。模型、推理强度和开发者角色指令逐字段取自现有 `/Users/huaodong/.codex/agents/coder.toml`（gpt-5.6-luna / medium），启动时保存该角色文件哈希与完整非敏感 argv。主线程只负责调度，代码仍由该 coder 角色执行。

两组均使用 workspace-write 沙箱和同一自动审批机制，并通过官方特性开关关闭 memories 与 multi_agent，防止历史注入和递归增开执行者；这些设置不削弱审批或沙箱。角色指令、共享产品输入、环境变量名、依赖版本、启动入口和停止规则相同。默认配置中的其他可用工具不因组别变化。工作目录放在独立临时实验根下，避免上级受测 skill 仓库的自动发现。启动前记录适用 AGENTS 路径和本地 skill 发现位置；完成后审计 JSON 中实际读取/执行记录。审计只能证明可观察记录，没有读取记录的推理不能冒充可验证隔离。

首次终结性结果对应 CLI turn.completed、turn.failed 或明确阻塞的 final；进程异常退出保留为资源/运行中断，不偷偷重跑。JSON 事件、stdout/stderr、进程退出码、输出末条回复及可得 usage 原样封存。两组均使用这一入口，准备阶段内置代理结果不与正式组混算。

以首次终结性final交付或明确阻塞回报封存，正常进度不触发。允许代理自主测试修复；主线程仅处理基础设施，不作定向解题辅导。规格变更对两组同步并记录版本；受影响旧轮封存。两臂均封存后才评分；任何返工只在生产副本进行。

源代码、正文、命令及stdout/stderr/exit、结束状态与时间、可得token、环境差异一并保存。缺token写null，资源中断单列删失，普通遗漏不能冒充环境阻塞。首次成绩不可由后续成功倒改。

两名独立去标签评审；作者与主线程知道分组，不称双盲。共同产品门槛与声明真实性用于两组，EDD专用schema只核查skill流程，不用于扣控制组产品分。保留异议与主线程依据。后章统一继承修复验收后的skill产物，结论限定于此前置条件。

成本分准备、实现写作、执行检查、评审、生产返工；不以并行墙钟时间冒充单代理计算量。每章一对是探索性观察，不设收益百分比或统计推广。

首次运行前评估器必须用已知正确与预植错误自检。整体以真实代码行为、中文教程可复跑与原始证据核查为准。
