# ch06–16 产品行为澄清

这是共同产品规格。它约束读者实际可见行为，不规定执行者的工作流、记录模板或内部代码组织。每次仅实施当前章节，保留先前冻结接口与已有功能；若必须改变共有合同，先明确影响。所有演示默认离线，不读取个人仓库或向外发送材料。

## 各章共同交付

每章给出两种语言的可复用功能、从仓库根可运行的演示与有区分力的正常/异常测试，并完成 `docs/chapters/NN.md`、`NN-rust.md`。中文正文按实际操作推进：从上一章留下的问题开始，准备输入、执行命令、解释观察结果，再走读与该结果相关的源码和语言知识。解释失败为什么出现以及如何处理；练习有可执行检验或参考答案。共同锚点与练习编号一致，保留章号，不将模板目录或测试清单当成正文。明确对应可恢复章节快照，不能引用尚未建立的 Git 标签。

代码维持同一棵逐章演进树。独立示例仍调用可解释的实际机制，提供自己的输入、入口和 README，确保统一验证入口确实执行示例。测试要对来自临时工作区的输入作出行为断言，不能仅比较脚本预写的成功字符串。

## 06 循环控制

在实际 ch05 循环中落实模型轮次、工具调用预算、重复行动、取消与超时。明确计数单位及停止原因，达到上限前拒绝下一次派发；同轮多工具只执行预算允许的调用。取消或请求超时后不再派发新模型/工具动作，已经开始的请求按传输可取消能力结束或被隔离，不把其迟到结果当作当前成功。重复判断基于动作身份与参数，允许配置阈值。演示分别触发可解释的停止原因，正常任务仍能完成。

## 07 上下文管理

规则、当前目标、完整历史和待发上下文分别表示。构造受限预算下的长历史失败，比较管理前后发给模型的消息。预算不足以容纳必须保留的内容时明确返回失败/停止原因，不静默删除规则或目标。裁剪以完整调用及结果为单位，不留下孤立 tool result 或半个多调用回合；完整审计历史仍可检查。上下文用量注明估算方法，不能假称服务实际 token。

## 08 四种方法

在固定的同一组材料、问题、答案事实和预算下，实际构造按需读取、窗口、摘要、检索四种上下文，并把构造结果送到统一回答/评测入口。方法名称必须对应不同机制：按需读取从索引选择后读真实文件；窗口保留最近完整片段；摘要通过明确的压缩程序/适配器产生较短内容；检索根据问题匹配候选材料。任何离线回答或摘要逻辑的限制写清楚，不能按策略名直接返回预置分数。保留输入、选中材料、估算用量、原始回答、正确性判定和实际测得的本地耗时，服务 token 不可得时为 null。两语言提供可独立运行的示例；反例应展示信息丢失或检索遗漏怎样影响回答。

## 09 验收与验证器

验收条件由结构化数据描述，测试、类型检查、运行时与声明式断言分别有实际执行的适配器。验证结果包含状态、可见证据及证明范围。演示真实返回零却没有完成任务的程序，以及满足内容条件的程序。外部命令用参数数组、受限工作目录与超时运行，保留 stdout/stderr/exit；空测试不能冒充执行过测试。独立双语言示例中，读者可改变候选产物使某项验收转为失败。

## 10 失败反馈

在真实验证结果上区分可修复错误、需重规划错误、无法自动处理错误和取消；转换为包含位置/原因/已尝试动作的反馈。修复策略实际改变候选后重新验证，有清晰次数上限和终态。不可修复时进入人工接管，不能把重复原动作称为重规划。运行中的子进程或资源在取消、超时、异常和正常结束时有清理路径；用实际活动进程证明清理，不仅检查布尔标记。

## 11 防御性编程

在执行工具前验证类型、必填项、范围与真实路径，覆盖 `..`、绝对路径、末级与父级 symlink 越界。来自文件和工具的文本仍是数据，不能修改执行权限。日志、错误与最终输出的敏感信息策略要有具体输入例子及检查，凭据不得进入演示快照。副作用以稳定执行标识及状态区分未开始、执行中、成功、失败、结果未知；遇到未知结果不得自动重复执行。提供独立示例及实际副作用计数断言，注明进程内账本和持久化账本各自边界。

## 12 权限与差异审查

权限决策实际挡在读/写工具与文件系统之间，有 allow/deny/needs_approval 三种结果。补丁是具体路径、基线内容摘要和拟写入内容/差异，预览不能写文件。批准绑定整个具体补丁与文件基线；改变补丁、换文件、文件在批准后变化均使原批准失效。拒绝及未批准状态保持工作区内容不变。限制作用于规范化后的真实路径，不能通过 symlink 换出批准范围；多文件补丁先核验全部基线，失败不留下部分写入。分别演示允许只读、请求修改、拒绝、批准后应用和旧批准过期。提供双语言独立示例，后章复用此接口。

## 13 计划与恢复

计划节点含依赖、验收、状态和必要审查；依赖没有完成验收不得派发。计划修改有可追踪版本，事件持久化后可在新进程/新实例恢复。演示至少在执行前、执行后未确认结果、验收前中断。持久事件必须足以区分可重试的纯读取和可能已发生的副作用；未知副作用等待核实或人工处理。恢复不能把历史输出当成当前文件仍有效的证明。

## 14 多智能体协作

通过真实的异步子任务执行器展示串行与有界并发。模型可离线回放，但子任务实际工作、耗时和访问必须发生；不能预填结果模拟并发。子任务权限和预算由父任务收窄，提交更大权限应拒绝。取消传播到未开始和正在执行的任务，最终记录已完成/失败/取消/未知。汇总必须保留每项产物与证据，不用单个成功覆盖部分失败。两个任务拟修改相同规范化文件时，在写入前检测冲突并交给协调者处理，不让最后完成者静默覆盖。独立示例和测试记录最大同时活跃任务数，覆盖部分失败、取消、权限扩大和路径别名冲突。

## 15 本地 MCP 扩展

按 MCP 2025-06-18 规范实现本章需要的真实 stdio 生命周期：启动本地文档检索服务，initialize/initialized，tools/list，tools/call，关联请求 ID，解析工具内容与 isError。一行一个 JSON-RPC 消息，stdout 仅协议，诊断走 stderr。两种语言客户端分别实际连接服务；不能直接调用服务函数替代传输。服务工具真实检索专用文档目录，调用走现有权限、超时和验证逻辑。覆盖未知工具、业务错误、协议/子进程错误、退出和取消清理。正文从这个接入点解释 MCP、Skills、Hooks 和 Plugin 各处于哪层，不承诺实现本章未做的完整协议。

## 16 文档维护助手

复用已经实现的检索、验证、批准和计划能力，读取源码/配置事实与文档，报告证据来源，生成可预览补丁，经批准实际修改并验证。固定 12 例只提供 workspace 输入给实现，评估方保管 expected/oracle。实现不读取 oracle、案例 ID 或目录名以选择答案；修复应从命令定义、参数/配置定义和真实链接目标推导。材料不够确定时可说明无法判定，不能编造 API。无须修改的 3 例应产生零修改。报告逐例正确性、误改、实际本地耗时和可得模型用量；离线本地耗时与真实模型服务耗时分开。保留真实模型显式选择入口，默认离线任务仍完整走发现、提案、批准、应用、验证。
