# 单章独立产品评审交接

你是独立评审者。只审查随后指定的两个去标签章节包及共同产品规格。不要寻找组别、受测skill、作者报告、长期记忆、其他评审结果或实验管理记录；不要修改实现或对另一评审提示结论。你不是唯一工作者，请仅在自己的审查临时目录和指定报告路径写入。

两份产品都需独立审查，两种语言都需检查。先阅读当前章正文与相关源码，按照正文的目录、命令、输入运行演示，核对观察值、解释、源码路径、练习编号及共同锚点。再核对共同规格的正常与失败行为，对核心边界设计能区分正确与错误实现的具体输入。在必要的临时测试中调用真实实现，不以名称、成功字符串或自带测试数目代替机制核验。不能删改产品原有测试。

分别报告：两种语言行为逐项 passed / failed / undetermined / not_run；双语言差异；正文是否完整可跟做及具体缺口；原有功能回归；亲自执行的命令、目录、stdout/stderr/退出码与时间。每个缺陷注明准确文件位置、触发步骤或输入、观察和影响。只给有依据的问题，不以产品是否带有某种工作流记录格式评分。不做加权总分，不推断组别。不要求真实服务来证明独立离线行为；真实服务单列未运行。

每份正文必须实际阅读与跟做；文件存在、关键词或字数不能证明教程质量。命令成功之后仍要看结果能否满足章内解释。正文描述的行为没有实现或仅演示固定成功输出，应明确指出。若两语言内部写法不同但合同与外部行为相同，不作为缺陷。

所有操作在副本中进行，Rust目标目录放副本之外的指定私有临时目录。审查结束后提交完整报告及原始命令证据，保留不确定事项。不要修改源码、修复产品、提交、推送或发布。
