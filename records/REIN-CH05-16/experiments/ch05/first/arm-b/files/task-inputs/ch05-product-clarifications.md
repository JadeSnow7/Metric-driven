# 第05章共同产品补充说明

本章交付一个真实可运行的核心 Agent Loop，以及 TypeScript、Rust 两篇完整中文教程。现有只读工具、统一消息合同、OpenAI 兼容非流式适配器、Anthropic 离线转换和共享样例是本章的最小前置工程。正文开篇说明如何接入，不把它们表述为前四章已完整交付。

## 核心行为

- 循环真实调用模型适配器；模型要求工具时，执行已注册的搜索与读取工具，把工具结果连同原调用 ID 放回消息历史，再次调用模型，直到获得最终回答。
- 工具操作真实的指定工作区文件。离线演示用确定性模型回放替代网络模型，仍必须真实搜索、读取和回传文件结果，不能把工具输出写死在回放里。
- 支持一次模型消息中多个工具调用，按声明顺序执行；每个调用恰有一个匹配 ID 的结果，再继续模型轮次。记录能核查此顺序及对应关系的运行事件和显式状态。
- 未知工具、工具参数错误和文件读取失败作为结构化工具失败回传，不能冒充成功；模型可根据反馈继续行动。模型适配器错误使运行失败，保存已发生事件，不能生成虚假的最终回答。
- 只有不含工具调用且包含非空文本的模型回复才是正常最终回答。空回复为明确失败。为防止失控提供默认最多32次模型轮次的基本保护，并返回可解释的停止原因；更完整的预算、取消、超时和重复检测留到第06章。
- 保持已有 hello 功能与前置消息、工具和模型接口兼容。接口扩展说明用途，内部实现遵循各自语言习惯。

## 演示与测试

提供单文件读取演示和多文件搜索后读取再总结的演示，能从正文命令直接执行。测试至少覆盖：正常最终回答；搜索→读取→回答；同轮多调用的 ID 配对与顺序；未知工具或读取失败的反馈；模型失败；空最终回复；基本轮次保护。检查模型收到的后续请求包含实际工具结果，而不是只检查工具被调用过。至少用两套不同的临时工作区内容验证结果受真实文件内容影响。

离线流程不得需要个人密钥。另提供可供后续单独真实冒烟使用的明确入口，复用 REIN_* 配置约定，便于限制最多4次模型调用且不自动重试。本次执行者只验证离线流程，不读取个人配置和凭据，不调用真实服务。
