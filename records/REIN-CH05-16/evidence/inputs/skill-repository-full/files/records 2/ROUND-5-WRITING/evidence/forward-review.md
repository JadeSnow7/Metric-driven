# 主代理对写作演练的审查

独立写作者只接收最终 skill 的隔离副本和 [三个情境](forward-input.md)，未接收 [主代理审查依据](review-criteria.md) 或本轮讨论。主代理读取了 [实际输出](forward-output.md)，并用 `diff -rq` 确认隔离 skill 与最终工作区 skill 一致。

| 情境 | 观察到的输出 | 判定 |
| --- | --- | --- |
| 教程开篇 | 从上一章读取文件进入，解释两种响应转换到同一结构的作用；用离线练习说明读者要做什么，网络与流式放在下一阶段 | 符合教程的学习目的，范围与材料一致 |
| 子任务进度与文档同步 | 立即报告 A 的实现结果；README 替换稿改为 `result.md`；摘要保留待复核、待写回状态；B 与整体未完成，最后由主代理整体验收和汇总 | 完成汇报、文档责任与状态表达符合要求 |
| 命令参考 | 直接给调用形式、必填参数、相对路径规则、固定输出和三种退出码；使用表格查询错误契约 | 符合参考文档用途，没有套教程开篇 |

写作者注明情境检查来自提供的日志，没有声称在本机执行，也没有将替换稿说成已写回真实仓库。进度场景仍可更简短，本轮依据是信息和结构是否适合用途，不按字数评分。这是三个虚构材料上的写作演练，未运行真实开发或同步流程。
