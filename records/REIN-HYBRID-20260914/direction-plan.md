## 冻结的首里程碑边界

- Rust 是唯一运行状态、预算、工具调用记录及结果采纳的权威；在已有 loop 中引入异步工具执行接缝，原入口仍用默认只读执行器。
- Node 执行 TypeScript 宿主，复用已有 `read_file` 工具，不调用 TS Agent Loop。首版单宿主、单在途调用。
- 简单 JSON-lines 协议包含版本、会话、任务、请求、工具调用标识、能力、取消及结果。stdout 用于协议，stderr 用于诊断；严格解析、有界输入、明确子进程回收。
- Rust 先执行固定工具许可和预算检查。宿主声明不能扩大 core 允许的能力。首版可信本地插件具有普通 Node 进程权限，独立进程不构成沙箱。
- 请求可能已送达后，畸形响应、断连或不确定取消记为 `outcome_unknown` 并停止运行，不自动重试、重启或进入下一模型轮。取消要实际发送、等待有界终态并回收宿主。
- 读文件结果以任务、调用、文件版本与读取规则关联证据。core 校验绑定和内容后才采纳；插件 success 不直接结算任务。此切片不声称已有一般领域验证框架。
- 调用记录本轮仅内存。持久恢复、批准记录、SDK 提炼、MCP、Hooks 等拆为后续明确任务，不在本轮宣称实现。
