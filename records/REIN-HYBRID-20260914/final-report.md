## 实际运行能力

Rust loop 通过 stdio 启动真实 Node 宿主，读取文件、检查 task/call/目标版本/规则关联、将采纳的工具结果送回第二次离线模型调用。取消、预算、调用记录与终态由 Rust 管理。取消需要匹配确认、干净 EOF、正常退出与实际回收；不能确认的派发结果明确保留为 outcome_unknown，不自动重放。

故障宿主分别注入错误身份、异常响应、半帧取消、重复终态、崩溃、无响应、超长消息、过期目标和写入临时 ledger 后断连。生产工具保持只读；故障 ledger 是专用测试副作用，不是持久化去重机制。当前首方 Node 进程是受信任进程，不是沙箱，内存 records 不是 journal。
