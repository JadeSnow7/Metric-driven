# 08 上下文管理方法：四种做法的横向对比

**状态：已提供｜可独立阅读｜限时免费**

第 07 章解决了“历史太长怎么办”，这一章继续问：同一份资料，应该在什么时候读、保留多少、怎样缩短、怎样定位？我们用六份冻结 Markdown 和四个问题做离线实验。`estimatedUnits` 是 UTF-8 字节教学单位，不是服务 token；没有启动真实模型服务。

## 从一次真实读取开始 {#methods-entry}

```sh
npm run --silent ch08:compare
```

命令由 Rust core 选择方法、计算预算并启动真实 Node `read_file` 宿主。Node 只负责领域文件工具，独立进程是进程边界，不是安全沙箱。每行都有 `messages`、`selectedSources`、`operations`、`estimatedUnits`、`quality` 和 `callRecords`，结论可以回到实际发送的消息。

## 固定资料与问题 {#fixed-dataset}

`fixtures/ch08-context/index.json` 只放文档 id、路径、标题、关键词和顺序；事实只在六份正文中。四个问题分别询问早期传输协议、最新检查命令、跨文档的批准与失败处理，以及资料没有给出的生产吞吐量。回答器只看到最终 `messages`，不能从题号或完整问题查固定答案。

## 四种方法 {#four-methods}

按需读取先用标题和关键词挑文档，再读取挑中的路径，因此不相关文档没有 `read_file` 操作。窗口按顺序读取，并从最早的完整片段开始裁剪；规则和问题永远是必要消息。摘要读取真实正文后只保留 `字段：值` 行，并保留 `[来源:docId]`。检索按问题词和关键词打分，同分按文档 `order` 稳定排序；分数帮助定位，事实仍必须来自正文片段。

四种方法处理的是同一组输入，不是四套答案表。把 `early-runtime.md` 的“传输方式”改成新值后，只要片段进入消息，回答也会变成新值；旧 oracle 不会替代新证据。窗口若裁掉事实，结果可以成功但 `insufficientEvidence` 为真或 `quality` 下降。问题和规则放不进预算（包括 `--budget 0`）时，状态是 `context_budget_exhausted`，不读文件、不调用回答器。

## 如何读比较结果 {#compare-results}

`status: completed` 只表示离线回答过程完成，不表示每个事实都有证据。`quality` 是有来源依据的必需事实数除以必需事实总数；没有必需事实的未知问题以空 claims 和 `insufficientEvidence: true` 表示。`serviceTokens` 始终为 `null`。`callRecords` 是 StdioExecutor 的真实记录，包含 `child_pid`、`dispatched`、`reaped`、`exit_code` 和 `terminal`，不是按策略名伪造的字段。

## 失败不是成功的别名 {#method-failure}

缺失文件、越界路径或宿主协议异常会产生 `error` 行，答案为空，且保留真实失败记录；断连不能因为子进程退出就猜成功。预算拒绝则不产生文档 I/O：

```sh
npm run --silent ch08:compare -- --budget 0
```

检查每行的 `status`、`modelCalls` 和 `operations`，而不是只看一个 `passed` 字段。

## 独立练习一：改事实，保留旧 oracle {#practice-08-1}

复制资料到绝对路径 `/tmp/rein-ch08-practice-1`，只修改副本中的 `docs/early-runtime.md` 的传输方式，然后运行：

```sh
npm run --silent ch08:compare -- --data-root /tmp/rein-ch08-practice-1 --strategy on-demand
```

预期 `task-01` 的 `messages` 含新值，`answer.rawAnswer` 和对应 claim 也含新值；`quality` 只按实际消息评分。结论：事实由证据驱动，而不是由旧 oracle 驱动。

## 独立练习二：零预算 {#practice-08-2}

使用原始绝对路径（替换为你的真实路径）：

```sh
npm run --silent ch08:compare -- --data-root /绝对路径/book/fixtures/ch08-context --budget 0
```

每行应为 `context_budget_exhausted`，`modelCalls` 为 0，`operations` 为空，`messages` 为空。结论：预算拒绝发生在文件读取和回答之前。

## 独立练习三：改变检索词 {#practice-08-3}

复制 fixture 到 `/tmp/rein-ch08-practice-3`，在副本任务中把问题词改为一个不出现在目标关键词中的词，再运行：

```sh
npm run --silent ch08:compare -- --data-root /tmp/rein-ch08-practice-3 --strategy retrieval
```

核对 `selectedSources`、每个 `operations[].score` 与 `answer.insufficientEvidence`。预期相关片段可能不再进入消息，证据不足被如实保留。结论：检索排序改变证据范围，不携带答案。
