# 08 上下文管理方法：同一份资料的四种取法

**状态：已提供｜可独立阅读｜限时免费**

## 从历史过长进入方法选择 {#methods-entry}

第07章解决了“消息太长怎么办”，但裁剪并不是唯一答案。本章把同一组六份中文资料和四个问题交给按需读取（`on-demand`）、窗口（`window`）、规则式摘要（`summary`）和检索（`retrieval`）。四者共享 Rust core 的预算、证据采纳和真实 Node 文件工具；离线回答器只看最后的 `messages`，不读取题目答案。

## 固定输入与可观察结果 {#fixed-dataset}

输入在 `fixtures/ch08-context`：`index.json` 只放标题、关键词和顺序，事实在六份 Markdown；`tasks.json` 的 expectedFacts 只供事后评分。每个规则都是独立 system message，正文证据以 `[来源:doc-id]` 开头。`estimated-bytes-v1` 不是服务 token，`serviceTokens` 始终为 `null`。

```bash
npm run --silent ch08:compare -- --data-root "$PWD/fixtures/ch08-context"
```

输出根对象含16行（4题×4方法），每行保留 `selectedSources`、`operations`、实际 `messages`、`estimatedUnits`、`quality` 和真实 `callRecords`。独立 Node 进程只是进程边界，不是安全沙箱。

## 四种方法的源码与取舍 {#four-methods}

实现集中在 `rust/src/rein/context_methods.rs`，入口是 `rust/examples/ch08_context.rs`。按需方法先以 index 关键词选文档，未选文档不会读取；窗口按 order 组织最近历史；摘要从真实正文保留 `字段：值` 行并保留来源；检索按问题词、关键词和正文相关度稳定排序。它们都走同一个离线回答器，从带来源消息识别字段生成 claims，不能把 taskId 映射成固定答案。

## 如何读比较结果 {#compare-results}

先看 `operations` 是否真的读了相应文件，再确认 claim 的 source 在消息中，最后比较 `estimatedUnits` 与 `quality`。任务三需要批准状态和失败处理两个来源；任务四没有吞吐量事实，正确结果是空 claims 与证据不足，而不是猜数值。

```bash
npm run --silent ch08:compare -- --strategy retrieval
npm run --silent ch08:compare -- --budget 0
```

预算为0时状态必须是 `context_budget_exhausted`，`messages`、`operations`、`callRecords` 为空且 `modelCalls` 为0，不发生文档 I/O。缺失文件、越界路径或 Node 宿主异常是 `error` 行并保留失败记录。

## 方法失败是系统行为 {#method-failure}

窗口裁掉事实时，证据不足是合法结果；读取失败时不能把空输出当成功。记录中的真实 argv、cwd、时间和退出码才允许事后判断。这里不调用真实模型服务，不能据此推断供应商 token、网络延迟或线上容量。

## 独立练习一：修改事实并保留旧 oracle {#practice-08-1}

复制冻结资料到绝对临时目录，只修改 `docs/early-runtime.md` 的传输方式，不改旧 expectedFacts：

```bash
tmp="$(mktemp -d)"; cp -R "$PWD/fixtures/ch08-context/." "$tmp/"; sed -i.bak 's/传输方式：JSON Lines/传输方式：Unix socket/' "$tmp/docs/early-runtime.md"; npm run --silent ch08:compare -- --data-root "$tmp" --strategy on-demand
```

核对 task-01 的 messages 含 `Unix socket`、rawAnswer 使用新值；旧 oracle 的 quality 下降，证明回答来自实际消息。

## 独立练习二：零预算 {#practice-08-2}

```bash
npm run --silent ch08:compare -- --data-root "$PWD/fixtures/ch08-context" --budget 0
```

所有行应为 `context_budget_exhausted`，`modelCalls` 为0、`operations` 为空。

## 独立练习三：改变检索词 {#practice-08-3}

复制资料后把任务问题中的“检查命令”改成资料不存在的词，再执行：

```bash
tmp="$(mktemp -d)"; cp -R "$PWD/fixtures/ch08-context/." "$tmp/"; sed -i.bak 's/最新发布文档中的检查命令是什么？/最新发布文档中的火星指标是什么？/' "$tmp/tasks.json"; npm run --silent ch08:compare -- --data-root "$tmp" --strategy retrieval
```

核对 `selectedSources`、排序和 `messages`：无匹配证据时 claims 为空并标记证据不足，不触发隐藏答案表。
