# 阅读指南

打开 Rein，你会看到一份逐章长大的工作区助手。它先学会接收一句话、取回模型回答，再逐步获得读取文件、连续行动、提出修改和验证结果的能力。01–03 章用 TypeScript 快速建立直觉；05 章以后 Rust core 负责权威运行时，TypeScript 负责宿主和领域插件。

我们沿着同一个项目往前走。每增加一项能力，就留下运行步骤、失败用例和能够解释的设计取舍。准备求职时，这些也是你可以拿出来展示、继续追问的具体材料。

| 你的路线 | 已有材料 | 下一步 |
| --- | --- | --- |
| TypeScript 入门 | [第 01 章 TypeScript 正文（修订中）](./chapters/01.md)，按需查阅 [阅读 0 TS 版](./readings/00-ts.md) | 用 SDK 发出 hello，逐步处理错误并验收 |

## 一套章节，逐步分工 {#languages}

章节顺序按 Rein 的能力递进。01–03 章以 TypeScript 为快速入门，Rust hello 作为可选准备；05 章以后不再把 Rust core 与旧 TS 页面描述成同主题双语言版本。

侧栏每个主题只有一个入口。页面上的 TS / Rust 按钮只用于阅读 0 和第 01 章这两个确实拥有对应版本的主题；05–07 的 Rust core 页面与旧 TS 对照页不显示语言切换。需要开始主线时，从第 01 章 TypeScript 正文进入，再转到 Rust core。

如果某版还未提供，页面会明确说明。旧快照和旧链接仍可恢复，但不代表当前主线存在对应实现。

对照小结关注相同输入、失败阶段和行为结果。所有权、错误表达或运行时的差异，在各自语言的相关位置展开。每页都沿当前主线即可学习；旧 TS 页面只在需要恢复历史行为时查阅。

## 怎样取得配套代码 {#code}

仓库的 `ts/` 与 `rust/` 放入门材料和 core/宿主实现。阅读 0 的练习位于各自的 `examples/reading-00/`，都是独立教学程序。第 01 章 SDK 调用代码在 `ts/src/` 与 `rust/src/`；第 04 章推导 provider adapter contract，第 06 章开始的 plugin stdio 见同章教程，两个边界分别说明。

跟随当前教程时，使用包含这些材料的工作版本。源码随章节累积，每章快照在相应内容完成并核验后记录。初版快照 `ch01` 保留手写 HTTP 版本；本次 SDK 教程使用 `ch01-helloworld`，具体说明见[第 01 章](./chapters/01.md#first-run)。新版标签仅本地交付时，远程克隆暂不可获取，需使用交付的本地仓库。

```bash
git tag --list
```

先查看已有快照即可。`git checkout ch01` 会切换整个仓库到历史提交，不是启动第一章，也不是切换网页语言。需要在历史版本上继续修改时，再按[阅读 0 的 Git 说明](./readings/00.md#git)保存工作并建立自己的分支。

正式书版发布时计划固定书版 tag，并对运行时合同显式版本化。当前还没有书版 tag；接口变化和适配将记录在 `MIGRATIONS.md`。

## 每章留下什么 {#evidence}

一条命令跑通之后，再追问一句，它检查到了哪里？

类型检查说明源码满足相应类型约束，测试说明列出的行为符合预期，历史回放说明已有响应怎样被解释。真实端点是否可用、回答是否解决了任务，需要各自的证据。

每章保留输入、运行方式、结果和未验证项。遇到失败，也留下报错阶段与下一步检查方向。后面复查项目时，你就能从结论找回具体过程。
