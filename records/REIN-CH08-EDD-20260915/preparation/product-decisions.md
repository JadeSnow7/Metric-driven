# ch08 前置产品决策

## 已冻结的共同架构边界

- ch08 使用单一 Rust `context_methods` 模块承接上下文策略、预算和结果采纳。
- 复用现有 `StdioExecutor`，由真实 Node 宿主执行文件读取；TypeScript 保持领域工具宿主，不复制第二套 Harness。
- 复用现有 `estimated_units` 语义；统一离线回答器只接收最终 messages。
- 本轮不扩展 M1 协议，不实现双 Harness，不宣称真实模型服务性能。
