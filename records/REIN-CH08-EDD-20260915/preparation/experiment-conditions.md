# 正式实验启动条件（主线程冻结）

- A→B→C 串行；三组使用同一 custom coder、`fork_turns=none`、同一本机 Node/Rust/Python 与产品输入。
- 每组独立工程、`target`、`node_modules` 和新执行上下文；共享下载缓存仅作环境差异记录。
- 每组最多 45 分钟墙钟，不设额外 token 上限；可取得的 token 字段原样保存，缺失为 null。
- 首次终结性交付或明确阻塞即封存；正常进度消息不中止；主线程首轮不提供定向反馈；单实现者不再派代理。
- 45 分钟未终结记为 `resource_interruption`，不得悄悄重跑。
- 允许同一类本地 loopback 测试及原地运行权限；无网络模型服务、提交、推送或发布。

准备阶段时间、依赖复制、沙箱复核与环境恢复成本单列，不计入正式实验成本。
