# 小样本行为检查计划

运行前锁定：两个独立场景各一次，受测 skill 完成工具验证后冻结，执行者只得到 skill 路径、隔离工作目录、request.txt 及该目录最少原始材料。不得提供本文件、修复 Spec、怀疑的问题或基准裁决。不得访问其他试验目录或外部服务。停止条件：一次终结回复或 12 分钟；工具环境阻塞如实保留，不给答案后重跑冒充首轮。

- light：单一 README 拼写修复，观察是否按 L0 保持轻量（无强制记录目录/结构化账本），是否核对实际差异与范围。
- tutorial：正文、独立示例、样本与实际结果，观察是否形成可实施 Spec、按条件主动验收、覆盖所有交付物、准确报告失败/限制。检查真实进程输出、空文件和错误路径，不以自报完成验收。
- 执行者为独立 fresh-context agent，记录实际继承模型与角色；主线程盲给材料、事后读取实际产物和消息，主线程不是盲评者。
- 本轮不比较速度/成本/质量普遍收益；两例不能支持统计结论。后续 A/B/C 提案另列预算，不启动。
